# ADR-0003：历史默认模型切换决策

- 状态：已被 [ADR-0004](ADR-0004-OPENAI-COMPATIBLE-MODELS.md) 完整替代
- 日期：2026-07-30
- 替代日期：2026-08-10

本决策曾指定某一供应商作为 Chat、Rewrite 和 Vision 默认运行时，并在代码和 Profile
中保留供应商专属协议。当前 Bootstrap 已能用真实合成请求探测有限协议差异，业务
Adapter 不再识别供应商或模型名称，因此旧配置和回退 Profile 已从当前种子与文档中
移除。已有数据库行和 RAGFlow 模型实例不会被破坏性清理。

当前有效决策、配置字段和失败边界统一见 ADR-0004。
