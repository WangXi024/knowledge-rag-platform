# 第一期测试用例与验收清单

> 当前实现覆盖说明（2026-08-19）：认证类用例当前改为 Tenant/User 两个 Header
> 的格式校验及组合 Scope 隔离；JWT 内容只在未来 Identity 接入后恢复。

## 1. 使用方法

本清单用于开发完成后的逐项验收。自动用例使用 Mock/Fake/最小非业务 Fixture；
`MAN-*` 用例由使用方使用自有文档手动执行。每项记录 Commit、镜像 Digest、
环境、执行人、时间、结果和证据链接。

## 2. 认证与隔离

| ID | 用例 | 预期 |
|---|---|---|
| SEC-001 | 无 Authorization 调业务 API | 401，RAGFlow/模型调用 0 |
| SEC-002 | 过期、错签名、错 iss/aud、禁用算法 | 401 |
| SEC-003 | 缺 `sub`/`tenant_id`/`rag_scope_id`/`jti` | 401 |
| SEC-004 | Body/Header 伪造 Scope 字段 | 400 或忽略不可信 Header，不能覆盖 Token |
| SEC-005 | A/B 列出知识库 | 各自只看到自己的资源 |
| SEC-006 | B Get/Patch/Delete A 的 KB/Document | 全部 404 |
| SEC-007 | B Get/Cancel A 的 Job/Request | 全部 404 |
| SEC-008 | B Get A 的 Citation/提交其 Feedback | 全部 404 |
| SEC-009 | Answer 混合 A/B KB ID | 整体 404，下游调用 0 |
| SEC-010 | A/B 使用相同 external/idempotency Key | 各自成功且互不可见 |
| SEC-011 | 构造跨 Scope 父子记录 | PostgreSQL 组合外键拒绝 |
| SEC-012 | 日志和错误抽查 | 无 JWT、原始 Claim、正文或越界信息 |

## 3. 知识库、文档和任务

| ID | 用例 | 预期 |
|---|---|---|
| OFF-001 | 创建/列表/详情/修改 KB | 状态、Profile、revision 正确 |
| OFF-002 | 同 Key 同请求重放 | 返回首次结果，不重复建 Dataset |
| OFF-003 | 同 Key 不同请求 | 409 `RAG-COMMON-009` |
| OFF-004 | 上传允许文件 | 202，Document/Job 建立 |
| OFF-005 | 空/超大/危险文件名/双扩展 | 稳定 4xx，无下游上传 |
| OFF-006 | Parse 到 READY | 状态、进度、Chunk 数和 revision 正确 |
| OFF-007 | Parse 失败后 Retry | attempt 增加且不无限重试 |
| OFF-008 | 执行中取消 | 状态最终一致 |
| OFF-009 | Worker 崩溃后租约恢复 | Job 被重新领取且不重复上传 |
| OFF-010 | 删除文档/KB | RAGFlow 与本地映射一致，可重复调用 |
| OFF-011 | Gateway 写完 `.ready` 后 Worker 跨容器读取 | 使用同一 staged ID，上传成功后文件删除 |
| OFF-012 | 上传中断/文件缺失/Hash 不匹配/符号链接 | 不上传 RAGFlow，返回稳定错误 |
| OFF-013 | 失败文件和孤儿文件超过 TTL | Scheduler 安全清理，活跃 Job 文件保留 |
| OFF-014 | 暂存卷达到配置总量 | 503 `RAG-DOC-010`，不创建不可恢复 Job |

## 4. 检索、问答和引用

| ID | 用例 | 预期 |
|---|---|---|
| ONL-001 | 纯检索 | 返回稳定项目 ID、分数和位置，无 RAGFlow ID |
| ONL-002 | 无候选检索 | 200、空 candidates |
| ONL-003 | 有证据非流式问答 | 返回 LLM 生成答案、有效 Citation、usage |
| ONL-004 | 无证据问答 | 200、`outcome=no_evidence` |
| ONL-005 | 模型伪造引用标签 | 修复或拒答，不返回无效引用 |
| ONL-006 | SSE 正常 | sequence 有序，completed 结束 |
| ONL-007 | SSE 中途错误 | error 后关闭，无 completed |
| ONL-008 | 客户端取消 | 下游 HTTP 取消，状态最终 CANCELLED |
| ONL-009 | Reranker/LLM 超时 | 有限降级或稳定错误，无无限重试 |

## 5. 缓存

| ID | 用例 | 预期 |
|---|---|---|
| CAC-001 | 完全相同请求 | Exact Hit，`cache_type=exact` |
| CAC-002 | 同 Scope 相似问法达阈值 | Semantic Hit，`cache_type=semantic` |
| CAC-003 | B 提交与 A 完全相同问题 | 不能命中 A，正常检索 |
| CAC-004 | 注入其他 Scope 高相似候选 | 被 Scope Filter 拒绝 |
| CAC-005 | revision/Profile/模型/语言变化 | 不命中旧缓存 |
| CAC-006 | 引用文档删除或非 READY | 候选失效，重新执行 RAG |
| CAC-007 | 单次缓存命令/Embedding 故障 | `cache_type=none`，正常链路继续；不等同于统一 Redis 进程停机 |
| CAC-008 | TTL 到期/重复 Upsert | 到期失效、写入幂等 |
| CAC-009 | Bootstrap 创建/重复校验向量索引 | 首次创建、重复无副作用 |
| CAC-010 | 模型或向量维度与现有索引不同 | Ready 失败 `RAG-CONFIG-005` |
| CAC-011 | 并发写入后检查 Hash/TTL | 无部分字段、无永久脏记录 |

## 6. RAGFlow Contract 与 Compose

| ID | 用例 | 预期 |
|---|---|---|
| DEP-001 | `validate_spec.py` | 通过 |
| DEP-002 | `docker compose config` | 通过，只有 Gateway 有 ports |
| DEP-003 | `up -d --build` 一条命令启动 | 构建、存储、RAGFlow、迁移、Bootstrap、应用按依赖健康 |
| DEP-004 | RAGFlow PostgreSQL 初始化 | 成功，无 MySQL 连接日志 |
| DEP-005 | RAGFlow 生命周期 Smoke | Dataset/Upload/Parse/Chunk/Retrieve/Delete 通过 |
| DEP-006 | 重启所有服务 | 数据和映射保留 |
| DEP-007 | 统一 Redis Stack 停止并恢复 | 停止时 Ready 稳定 503；恢复后缓存、Celery 和 RAGFlow 状态链路重新可用 |
| DEP-008 | RAGFlow/ES 停止 | Ready 失败，业务返回稳定 503 |
| DEP-009 | 上游网络扫描 | 只可达 Gateway |
| DEP-010 | Profile 首次/重复导入 | 首次插入、相同 checksum 幂等 |
| DEP-011 | Profile 同版本不同内容 | Bootstrap 失败 `RAG-CONFIG-003` |
| DEP-012 | Apple Silicon Compose 配置 | 仅 RAGFlow 为 amd64，自研镜像原生构建 |
| DEP-013 | `up -d --build` | 构建镜像，Migration/Bootstrap 后启动应用 |
