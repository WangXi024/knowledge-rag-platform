# 测试与验收规范

验收必须区分代码检查、模拟测试、真实依赖联调和业务质量。历史证据见
[验收报告](../../docs/ACCEPTANCE_REPORT.md)，原生图谱的逐项手动步骤见
[GraphRAG 验收清单](../../docs/NATIVE_GRAPHRAG.md#7-手动验收清单)。

## 1. 执行与证据规则

本机内存有限，测试并发固定为 **1**；逐项执行检查、测试和构建，不同时启动后端
测试、前端构建或多套服务栈。使用独立合成输入和隔离测试资源，不读取或输出真实
密钥，不把业务文件发给无授权的端点。真实模型调用与服务启动单独安排，不能由
Mock 用例隐式触发。

每次记录代码版本、命令/场景、运行环境、通过/失败/跳过、脱敏 request_id/job_id、
版本和预期结果。环境缺失或跳过不能记为通过；没有观察终态不能记为成功。
失败先定位再选择必要的定向复验，不为了补数量并发重跑整套测试。

## 2. 分层门禁

| 顺序 | 层次 | 必须核验的行为 |
| --- | --- | --- |
| 1 | 静态与规格 | Python 格式/类型、前端 TypeScript/lint、OpenAPI/规格引用、冻结 Profile 和 SQL 一致性 |
| 2 | 领域与应用单元 | 状态转移、范围、版本、幂等、失败恢复、迟到写回保护；使用 Fake/Mock |
| 3 | API / Adapter 契约 | 参数/错误/SSE、真实代码对合成上游响应的解析、过滤旁路、超时和非法协议处理 |
| 4 | 前端组件与生产构建 | 身份和资源请求、草稿保护、异步状态、错误与取消文案、受限 BFF 写路径；构建不等于服务验收 |
| 5 | 数据库/缓存集成 | 隔离测试库的组合外键、Scope、租约、唯一在途任务、迁移前提、缓存边界及索引兼容 |
| 6 | 真实依赖 Smoke | 逐项模型请求、模型登记、RAGFlow 上传/解析/检索、Worker 恢复和实际原文引用 |
| 7 | 人工质量与运维 | 使用方黄金集、错误引用、图谱收益对照、资源峰值、备份恢复及部署边界 |

默认关闭可选能力时，已有普通 RAG 路径应继续通过。启用能力不能以“请求返回 2xx”
替代结果校验：上传接收不等于 READY，构图 202 不等于 READY，模型登记不等于图谱
已构建，流式输出片段不等于最终引用有效。

## 3. 隔离与故障必测项

- TENANT 测试库在另一租户身份下不可见；同租户共享与 SYSTEM 合法共享按各自规则
  验收。资源共享不得共享主体的请求记录、幂等或缓存命中范围。
- 文档候选失败保留旧版，发布与回滚推进内容边界；已删除/退役来源不能迟到发布为
  当前可引用结果。
- Redis 通知失败不丢失已提交 Job；Worker 恢复和重试有界，失去租约后不能覆盖结果。
- 外部模型、RAGFlow、Rerank 或图谱失败按能力边界降级，不能伪造引用或跨范围兜底。
- 图谱元数据/文档过滤旁路、活动物理 ID 严格一致、旧图缓存隔离和空图均有明确断言。
- 构图提交结果未知时不盲目重提；取消上游终态不可观察时保留 CANCELLING，不能
  因任务记录消失、超时或关闭页面报告已经停止。

## 4. 当前 GraphRAG 验收状态

图谱全局与知识库默认关闭；已有实现和对应模拟用例可以审阅。四组模型的最小真实
API 请求通过，证明所测请求形态可调用，不证明全部 Bootstrap 参数或 RAGFlow 原生
调用路径兼容。配置→真实构图→READY→检索→原文引用→内容变更/取消的完整流程
仍待当前环境单独验收，业务质量与容量也未据此证明。

临时 Kimi K3 只作为临时配置，不为它修改代码或专用 Token 参数。对不兼容结果如实
记录，不放宽来源、隔离、终态或协议断言来换取“通过”。
