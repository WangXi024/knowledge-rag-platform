# 安全与威胁模型

本规格描述当前控制及明确缺口，不表示已具备生产身份或安全认证。身份演进详见
[Identity 接入策略](../../docs/IDENTITY_INTEGRATION_STRATEGIES.md)，原生图谱边界详见
[接入与验收说明](../../docs/NATIVE_GRAPHRAG.md)。

## 1. 身份与授权边界

当前业务 API 使用 `X-Tenant-ID`、`X-User-ID` 派生调用主体 Scope；它们是联调标识，
不校验身份所有权，不是密码、JWT 或可信管理员会话。当前
`TrustedNetworkManagementAccessPolicy` 依赖外部可信网络，不执行角色鉴权；前端
选择“租户/系统管理员”只是界面模式，不能作为权限证据。

因此，仅在受控可信网络使用当前管理接口；对外部署前需接入可信 Identity、服务端
管理授权和传输安全。不能因为 UUID 难猜、接口有身份 Header 或页面隐藏按钮就宣称
生产安全。普通用户端不新增图谱编辑入口，也不能替代后端最终授权。

TENANT 资源按租户范围共享，SYSTEM 资源按系统共享策略可读；调用主体 Scope 与
资源 Scope 分开。Repository 必须显式限定资源范围，跨范围和不存在统一处理；
请求历史、幂等和答案缓存仍隔离调用主体。系统合法共享不应误测为跨租户漏洞。
服务端派生的 `security_scope_id` 是数据库隔离键，调用方不能以任意 Header 或资源
UUID 替代它；资源仓库查询与组合外键都必须携带该范围。

## 2. 主要威胁与当前控制

| 威胁 | 当前控制与验收重点 |
| --- | --- |
| 伪造身份或管理员角色 | 当前 Header 不可信，网络边界是临时前提；生产身份/权限尚未完成 |
| 猜测 UUID、跨 Scope 关联 | 服务端资源策略、显式 ScopedRepository、组合外键与统一不可见响应 |
| 文档版本或缓存泄漏 | 活动版本映射、内容/策略/图谱版本缓存边界、引用回读；不可核验图谱跳过相关缓存 |
| 提示注入与图谱生成内容冒充原文 | 文档/图谱内容视为不可信数据；图谱只供有限导航词，答案证据须回到原始 Chunk |
| 过滤绕过 | metadata_filter/document_ids 请求跳过无法表达该限制的原生图谱路线 |
| 候选或退役物理版本进入原生聚合 | 本地全部 READY 活动 ID 与上游全部物理 ID 严格相等，否则阻断图谱路径 |
| 重复收费动作或迟到写回 | 持久化 Job、唯一在途任务、提交检查点、租约/CAS、内容和配置版本发布检查 |
| 取消误报 | 上游任务记录消失不算停止证据；无法确认终态保留 CANCELLING |
| 密钥、内部堆栈或上游内容泄漏 | 私有配置、按进程最小注入、稳定脱敏错误，公共诊断不暴露引擎标识或凭据 |

## 3. 模型、文件与数据最小暴露

模型端点、API Key、账号密码只进入已授权的私有配置/管理员环境，不写入源码、
Profile、测试 Fixture、聊天或日志。Graph Chat 三元组独立显式提供，不隐式复制
Gateway 配置；业务运行时只接收非敏感模型引用。图谱默认关闭，启用可能把抽取
上下文发送给所配置的模型端点并产生费用，应使用获授权的模型和数据。

仅由应用资源映射得到 RAGFlow Dataset/文档 ID，不允许公共 API 接受任意引擎目标。
Adapter 校验路径、响应、分页和归属；共享上传暂存只用于当前合法流程。应用与
RAGFlow 的数据库角色和数据归属隔离，不能通过内部表或索引旁路权限检查。

关闭开关不会删除密钥、回滚数据库或证明上游收费任务已终止。版本清理与恢复遵守
已授权生命周期和备份流程，不通过清库、删历史或放宽范围校验修复图谱阻断。

## 4. 验收与尚未覆盖的风险

隔离、过滤、密钥不回显、未知提交和取消分支使用合成输入逐项验收；测试并发 `1`，
不同时启动多套测试/构建或完整栈。四组最小模型 API 请求通过不证明原生 GraphRAG
完整流程已经真实集成，更不证明生产安全、业务准确率、抗注入或容量稳定性。

临时 Kimi K3 不改变本期代码或专用 Token 参数。没有真实来源、隔离和终态证据时
保留待验收结论；生产认证、细粒度管理授权及完整运维安全仍属于独立交付门禁。
