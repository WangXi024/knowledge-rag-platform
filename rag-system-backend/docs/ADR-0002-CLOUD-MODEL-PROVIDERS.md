# ADR-0002：历史云端模型拆分决策

- 状态：已被 [ADR-0004](ADR-0004-OPENAI-COMPATIBLE-MODELS.md) 完整替代
- 日期：2026-07-30
- 替代日期：2026-08-10

本决策曾把模型职责绑定到特定云端供应商和厂商命名的 Profile。当前实现已经完成
供应商无关迁移，不再保留旧环境变量、默认模型或回退 Profile。历史部署数据库中已经
导入的不可变 Profile 行不会被自动删除，以免破坏已有知识库引用；新部署、新资源和
文档均以 ADR-0004 为准。

RAGFlow 固定版本、PostgreSQL、Scope 隔离、不修改 RAGFlow 源码，以及模型/维度变化
必须创建新索引世代等安全决策仍然有效。
